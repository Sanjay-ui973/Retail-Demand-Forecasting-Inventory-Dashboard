# Retail Demand Forecasting & Inventory Analytics Dashboard

## Project Overview
This project focuses on retail sales analysis and inventory analytics using Microsoft Power BI and Excel.

The dashboard helps analyze sales performance across different regions, products, and categories.

## Dashboard Preview

![Power BI Dashboard](Dashboard%Screenshot.png)

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- Data Visualization

## Project Objectives
- Analyze retail sales performance.
- Identify top-performing regions.
- Understand product and category performance.
- Analyze profit trends.
- Present business insights through interactive dashboards.

## Key Insights
- South region recorded the highest sales.
- East region recorded the lowest sales.
- Electronics category generated the highest profit.

## Project Features
- Data Cleaning and Transformation
- Sales Analysis
- Regional Performance Analysis
- Product Performance Analysis
- Interactive Power BI Dashboard
